## Prepared description draft

> Frog-Out is a playful browser physics party game for 2–8 friends. Run, charge-jump and swing around Canopy Courtyard with a pulling tongue—or grapple another frog and send both players flying. In Outbreak, one player starts as Patient Zero. Poison spreads through frog-body contact, never through tongues. Stay healthy to earn survival points, then join the hunt once infected. Everyone becomes Patient Zero once; the highest cumulative score wins, with shared victories for ties. Create a room, share its code and play together on desktop or landscape touch controls. No player accounts or installation are required. Built with OpenAI-assisted development.

This is a draft, not a submitted description. If remaining on Free Render, add a brief availability note in a suitable submission field: “The first load after inactivity may take about a minute.” Do not claim iOS verification before the physical test.
