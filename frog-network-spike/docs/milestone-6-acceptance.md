# Milestone 6 personal acceptance playtest

Public URL: https://frog-out-milestone-2.onrender.com/

Open the URL on each device. Name/create room, share its code or Copy Join Link, join, everyone Ready, host Start Outbreak. Phones use landscape; fullscreen is optional; Sound starts off and can be enabled with its button. Desktop uses WASD/arrows + Space. Touch uses direction/aim plus action; tap/release jump, hold/release charge, airborne press/hold grapple and release detach.

1. Play at least one complete 2-player match, then 4–8 players if available. Does the courtyard give enough breathing room while preserving encounters? Can you chase, intercept and escape along ground, side ledges and upper beam? Try corners/high ledges for camping or dead ends.
2. Compare normal/charged jumps, air momentum, terrain swing/release and reciprocal frog pulling to approved M5. Controls and rules have not been intentionally retuned.
3. Identify every frog during clustering. Check healthy, crown/Patient Zero, GRACE, POISON/X cheeks and offline states; try judging with reduced color saturation if useful. Can you follow tongues and see attachment without effects obscuring contacts?
4. Check the short reveal/countdown, live timer/survival points, infection feedback, round Survival + Bonus = Score table, cumulative/final standings and shared winners. Host continues/returns to lobby as before.
5. Phone/tablet landscape: aim + action simultaneously, terrain/frog grapple/release, keyboard/touch switching on hybrid devices, fullscreen enter/exit if supported, rotate and reconnect. Check frog/name readability on the smallest device and that controls/HUD do not cover the arena. Results may scroll vertically or horizontally on small screens.
6. Enable optional Sound. Listen for jump/charge, fire/attach, infection, countdown/start/results cues; toggle off. Check cues add clarity without becoming tiring. No music is included.
7. Refresh a player during a round. Confirm same frog, offline cue and restored controls/state. If feasible, disconnect for over 30 seconds: others return to lobby, as approved.

If an issue occurs, use Diagnostics during gameplay and send the JSON, device/browser, approximate time/room code and a short screen recording or description. Explain whether it is geometry/readability or a difference in controls/physics/network feel. Diagnostics do not include the reconnect token.

Automated tests do not approve this milestone. Stop here pending the user's personal acceptance.
